# 📚 Rezolvări PbInfo

Acest proiect reprezintă un site web dedicat soluțiilor pentru problemele de informatică de pe platforma [PbInfo.ro](https://pbinfo.ro). Site-ul conține peste 2300 de probleme rezolvate, fiecare verificată să obțină 100 de puncte. 💯

## 💡 Despre proiect

- **🎯 Platforma țintă**: PbInfo.ro - o platformă educațională românească pentru probleme de informatică.
- **📊 Număr de probleme**: Peste 2300 de soluții disponibile.
- **✅ Verificare**: Toate soluțiile sunt testate și obțin scorul maxim (100 de puncte).
- **🔍 Interfață**: Site web simplu, cu căutare după ID-ul problemei.

## 🌐 Demo

Poți accesa versiunea live a site-ului la: [https://itsiamdev.github.io/rezolvaripbinfo.ro/](https://itsiamdev.github.io/rezolvaripbinfo.ro/)

## 🚀 Cum să folosești

1. 🌐 Deschide `index.html` în browserul tău.
2. ✏️ Introdu ID-ul problemei în câmpul de căutare.
3. 🔎 Apasă butonul "Caută" pentru a vedea soluția.

## 📁 Structura proiectului

- `index.html`: Pagina principală a site-ului. 🏠
- `script.js`: Script-ul JavaScript pentru funcționalități. ⚙️
- `style.css`: Stilurile CSS pentru interfață. 🎨
- `problems/`: Directorul cu fișierele HTML pentru fiecare problemă rezolvată. 📂
- `icon.jpg`: Iconița site-ului. 🖼️
